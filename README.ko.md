# harness-cockpit

Claude Code 프롬프트 위에 3줄짜리 띠를 붙여, **지금 이 세션이 무엇을 하고 있고 얼마나 남았는지**를 한눈에 보여 주는 mod.
툴 호출을 막거나 바꾸지 않는 **보기 전용**이다.

![작업 중인 띠](docs/img/band-working.png)

English: [README.md](README.md)

띠 한 장에 들어 있는 것 — 왼쪽부터 Clawd(와 하늘) · 진행 단계 · 세션과 레포 · 서브에이전트와 감시 · 토큰 사용량 · 해가 지나가는 반원과 퇴근까지 남은 시간.

> 「실제 화면」 절 앞의 그림은 설계 화면이다.

## 설치

Claude Code 터미널 세션의 프롬프트에서 한 줄을 친다.

```
/plugin install harness-cockpit --marketplace KimGyuBek/harness-cockpit
```

`Add marketplace?` 에 `y`, 범위는 Enter(user). 설치하면 그 세션부터 바로 띠가 뜬다.

저장소를 받아서 써 보려면 `claude --plugin-dir <받은 폴더>`.

### 필요한 것

| 항목 | 내용 |
|---|---|
| Claude Code | mods 를 쓸 수 있는 버전. 2.1.291 ~ 2.1.293 에서 만들고 확인했다 |
| 운영체제 | macOS 에서만 확인했다. 맥 자원(CPU · 메모리)과 화면 안 꺼짐은 macOS 명령(`iostat` · `memory_pressure` · `pmset`)으로 읽는다 |
| 터미널 | 24비트 색을 권한다. 256색에서도 뜨지만 하늘과 Clawd 색이 거칠다 |
| 창 폭 | 127칸에서 전부 보인다. 좁아지면 반원 → 사용량 알약 순으로 접고 글자로 남긴다 |

## 띠 읽는 법

| 자리 | 보이는 것 |
|---|---|
| 왼쪽 그림 | Clawd 와 뒤 하늘 |
| 1줄 | 이슈 키 │ 진행 단계 ··· 원격 표시 · 상태 배지(작업중 · 하위 N 작업중 · ✔ 완료 · 쉼 N분 · 결정 대기) |
| 2줄 | 세션(이슈) 제목 │ ● 레포 │ ◆ 모델 · effort |
| 3줄 | 서브 · 감시 · 워커 · 띄운 것 수, `caffeinate` |
| 오른쪽 알약 | ctx(컨텍스트) · 5h · 7d 한도 사용률 |
| 오른쪽 반원 | 해 · 달의 위치, 퇴근까지 남은 시간, 요일 |

## 기능

### 진행 단계

`✓ 플랜 ── ● 구현 ── ○ 검증` 처럼 지금 어느 단계인지 보인다. 구현 작업은 플랜 → 코드 → 구현 → 검증 → 완료, 조사 작업은 조사 → 정리 → 보고.

- 단계는 Claude 가 쓰는 도구를 보고 자동으로 판정한다.
- mod 가 `phase` 라는 툴을 하나 등록한다. Claude 가 이 툴로 단계를 알리면 그 값이 먼저다. 규칙 문서(CLAUDE.md)에 「단계를 넘길 때 `phase` 를 한 번 부른다」 한 줄을 넣어 두면 정확해진다.
- 색은 상태를 말한다 — 끝난 단계 초록, 진행 중 파랑, 결정 대기 노랑, 막힘 빨강.

### 토큰 사용량 알약

`ctx 11%` `5h 32%` `7d 5%` — 컨텍스트와 5시간 · 7일 한도. 값만큼 알약이 색으로 차고, 색은 5단계(30 · 50 · 70 · 85% 경계)로 바뀐다. 값을 아직 모르면 `—`.

### 반원 · 퇴근 타이머 · 요일

점으로 그린 반원 위를 낮에는 해가, 밤에는 달이 지나간다. 설정에 위치(`location`)가 있으면 그날의 일출 · 일몰을 계산하고, 없으면 06:00 · 18:00 으로 고정한다.

- 반원 안의 숫자는 **퇴근까지 남은 시간**(`4h18m` · `42m` · `quitTime` 을 정하지 않으면 18:00 기준). 가까울수록 회색 → 초록 → 연두 → 노랑 → 주황 → 빨강, 마지막 10분은 깜빡인다. 퇴근 뒤에는 넘긴 시간(`+23m`)이 보라색으로 나온다. 주말에는 나오지 않는다.
- 아래 줄은 주간 띠(월화수목금, 오늘이 밝게).

![밤](docs/img/band-night.png)

### Clawd

띠 왼쪽에 사는 마스코트. 세션이 하는 일에 따라 움직인다 — 생각하기 · 읽기 · 고치기 · 실행하기, 엔터를 치면 「넵」, 턴이 끝나면 환호, 오류가 나면 깜짝.

**맥 자원을 몸으로** — CPU 와 메모리 중 높은 쪽을 따라 붉어지고 땀 · 김 · 떨림이 붙는다. 숫자나 문구는 띄우지 않는다.

![자원 단계](docs/img/clawd-heat.png)

| 단계 | 기준 |
|---|---|
| 주의 | CPU 50% 또는 메모리 75% |
| 높음 | CPU 80% 가 30초 또는 메모리 85% 또는 메모리 압력 경고 |
| 위험 | CPU 95% 가 60초 또는 메모리 93% 또는 메모리 압력 위험 |

**퇴근 무렵** — 평일 퇴근 5분 전부터 5분 뒤까지 Clawd 가 선글라스를 쓰고 춤춘다(자던 세션도 일어나고, 일하는 중에도 선글라스는 쓴다). 그 뒤 퇴근 1시간 뒤까지는 주저앉아 한숨 쉬고 눈물을 흘린다. 그 뒤로는 평소대로다.

**뒤 하늘** — Clawd 칸 바탕이 아침 · 낮 · 노을 · 밤으로 바뀌고 구름 · 별이 뜬다.

![하늘 네 가지](docs/img/skies.png)

**졸기와 잠** — 세션이 5분 넘게 쉬면 Clawd 가 꾸벅꾸벅 존다. 15분이 넘으면 눈을 감고 자고, 시각과 상관없이 밤하늘에 노란 반달이 뜬다. 60분이 넘으면 띠 전체가 흐려진다. 프롬프트를 치면 바로 돌아온다. 쉼은 세션마다 따로 센다.

![쉬는 세션](docs/img/band-sleep.png)

### 작업 중 테두리

테두리 색은 레포 계열을 말한다(기본 파랑, 설정에서 정한 계열은 빨강). 일하는 동안에는 테두리가 계열 색과 검정으로 0.6초씩 깜빡인다. 본체가 쉬어도 서브에이전트가 일하고 있으면 작업 중으로 본다.

![하위만 작업 중](docs/img/band-sub.png)

### 원격 · 화면 안 꺼짐 표시

- Remote Control 이 켜져 있으면 배지 앞에 폰 모양이 뜬다.
- `caffeinate` 가 화면 잠자기를 막고 있으면 3줄 끝에 노란 글자 `caffeinate` 가 뜬다.

### 서브에이전트 · 감시 · 띄운 것

3줄의 칩으로 수를 보이고, `/cockpit` 을 치면 오른쪽 패널에 세로 목록으로 펼친다. 10분 넘게 소식이 없는 서브에이전트는 정체로 표시한다. 이 세션이 띄워 둔 것(docker 컨테이너 · 브라우저 · 아직 push 하지 않은 커밋)도 센다.

### 정해진 시각 효과

글자를 띄우지 않고 효과만 낸다. 열려 있는 세션 전부에서 같이 재생된다.

| 언제 | 효과 |
|---|---|
| 설정의 `bells` 에 적은 평일 시각 | Clawd 가 종을 친다(음표) |
| 매 정각 | 반원의 해가 반짝이고 길 전체가 켜진다 |

### 띠 밖

![띠 밖 자리](docs/img/outside-band.png)

| 자리 | 내용 |
|---|---|
| 스피너 줄 | 지금 단계 · 돌리는 명령 · 몇 번째 도구인지 · 작업 도중 받은 메시지 수 |
| 턴이 끝난 줄 | 턴 영수증 — 끝난 시각 · 도구 수 · 고친 파일 · 실패 · 늘어난 컨텍스트와 한도 |
| 입력칸 아래 줄 | 남은 것 — 이 세션이 띄워 둔 docker · 브라우저 · 미push |
| `/now` | 지금까지 한 일 요약. 모델을 부르지 않아 토큰이 들지 않는다 |

### 그 밖에

- **세션 이름** — 이름이 비어 있는 세션에 한 번, 이슈 제목 앞부분으로 붙인다. 손으로 붙인 이름은 건드리지 않는다.
- **시작 효과** — 새 세션을 열 때 2~3초 재생된다. `/fx` 로 고르거나 끈다.
- **경보 줄** — 설정에 적어 둔 경보 파일이 살아 있는 동안 테두리가 두 줄 빨강으로 바뀌고 맨 위에 경보 줄이 생긴다.

## 명령

| 명령 | 하는 일 |
|---|---|
| `/now` | 진행 요약(토큰 0) |
| `/cockpit` | 오른쪽 패널 열기 |
| `/cockpit sky on\|off` | Clawd 뒤 하늘 켜기 · 끄기(저장됨) |
| `/cockpit sky morning\|day\|sunset\|night\|auto` | 하늘 시간대 미리 보기 |
| `/cockpit poll` | 요소별 폴링 주기 보기. `/cockpit poll sys 3` 처럼 바꾼다(저장됨) |
| `/cockpit idle` | 이 세션의 마지막 활동 시각과 쉼 단계 |
| `/cockpit fx bell\|hour` | 정해진 시각 · 정각 효과를 지금 한 번 재생 |
| `/cockpit fx party\|gloom` | 퇴근 무렵의 기분을 10초 동안 미리 보기 |
| `/cockpit config` | 읽힌 설정 요약. `/cockpit config reload` 로 다시 읽는다 |
| `/clawd on\|off` | Clawd 켜기 · 끄기 |
| `/fx` | 시작 효과 미리 보기(`/fx 1 3`) · 고르기(`/fx use 1 3`) · 끄기(`/fx off`) |
| `/leftovers` | 이 세션이 띄워 둔 것 목록 |

## 설정

선택 사항이다. `~/.claude/harness-cockpit.json` 을 만든다([docs/config.example.json](docs/config.example.json) 참고). 없어도 띠는 그대로 뜨고, 아래 항목만 빠진다.

| 키 | 뜻 | 없을 때 |
|---|---|---|
| `repos[].match` | 세션의 작업 폴더 경로에 대어 보는 정규식 | — |
| `repos[].name` · `color` | 2줄의 레포 이름과 점 색 | 폴더 이름을 흐린 색으로 |
| `repos[].family` | `red` 또는 `blue` — 테두리 색 | 파랑 |
| `repos[].brand` · `word` | 시작 효과에 쓰는 이름과 큰 글자 | 폴더 이름 |
| `alertFiles[]` | 있는 동안 띠를 경보로 바꾸는 파일. 그 파일을 만든 세션의 띠에만 뜬다 | 경보 없음 |
| `alert.title` · `note` | 경보 줄의 글귀 | 「경보 파일」 |
| `branchKey` | 브랜치 이름에서 이슈 키를 뽑는 무늬 | `ABC-123` 같은 대문자 키 |
| `serviceWindow` | 평일 정해진 시간대에만 켜지는 것(예: 개발 서버). 시작 효과의 브리핑 카드에 나온다 | 그 줄이 빠진다 |
| `location` | 일출 · 일몰을 계산할 위도 · 경도(시간대는 컴퓨터의 것을 쓴다) | 일출 06:00 · 일몰 18:00 |
| `quitTime` | 퇴근 시각 `HH:MM` | 18:00 |
| `bells` | Clawd 가 종을 칠 평일 시각들 | 없음 |
| `verifyCommand` | 「검증」 단계로 볼 명령을 더하는 정규식 | 기본 목록(jest · vitest · npm test 등) |
| `texts` | 몇몇 글귀를 내 말로 바꾼다(`leftClear` · `leftBusy` · `leftPane` · `boardHint`) | 기본 글귀 |
| `issue.mcpServer` · `keyPattern` | `get_issue` 로 이슈 제목을 주는 MCP 서버 | `linear`, `ABC-123` 같은 키 |
| `issue.boardCommand` · `boardLineDir` · `fleetRoot` | 만든 사람이 쓰는 작업 대장 · 여러 세션 관리 도구와 잇는 자리 | 그 칩이 빠진다 |

아직 코드 상수인 값은 하나다:

| 바꿀 것 | 파일 | 이름 | 기본값 |
|---|---|---|---|
| 졸음 · 잠 · 흐림 기준 | `hooks/model.js` | `IDLE_DEFAULT` | 5분 · 15분 · 60분 |

## 부하와 토큰

맥 한 대에서 잰 값이다. 자릿수만 참고한다.

| 항목 | 값 |
|---|---|
| 쉬는 세션 하나 | 코어 1개의 1.8~1.9%(전부 끈 세션 0.45%) — mod 몫은 많아야 약 1.4%p |
| 그중 Clawd 그림 | 약 0.8%p. 15분 쉬면 1초에 한 번만 그린다 |
| 토큰 | 요청마다 228개(`phase` 툴 하나). 그림 · 효과는 0 |
| 맥 자원 · 화면 안 꺼짐 측정 | 열린 세션 중 하나만 재고 나머지는 그 결과 파일을 읽는다 |

이벤트로 알 수 있는 값(작업 중 · 단계 · 도구 수 · 서브에이전트 · 컨텍스트)은 폴링하지 않는다. 잠든 세션은 폴링 주기를 6배로 늘린다.

## 알려진 한계

- 내 프롬프트 줄에 번호 · 시각을 붙이는 것은 엔진이 그려 주지 않아 못 한다. `/now` 의 프롬프트 목록으로 대신한다.
- 그림 칸(Clawd · 반원)은 터미널 테마를 알 수 없어 색이 고정이다. 밝은 바탕 · 어두운 바탕 모두에서 읽히는 색만 쓴다.
- GitHub 에서 `/plugin install` 로 설치하는 경로는 아직 끝까지 돌려 보지 않았다. `claude plugin validate` 통과와 `--plugin-dir` · `CLAUDE_CODE_PLUGIN_DIRS` 로 읽히는 것까지 확인했다.
- 비공식 mod 이고 Anthropic 과 관계가 없다.

## 구조와 개발

```
.claude-plugin/plugin.json        매니페스트
.claude-plugin/marketplace.json   이 저장소를 설치 가능한 마켓플레이스로 만드는 파일
hooks/register.js                 이벤트 관찰 · 상태 · 폴링 · 명령
hooks/model.js                    순수 로직(단계 판정 · 색 단계 · 쉼 · 글귀)
hooks/view.js                     띠 · 패널 화면 트리
hooks/clawd.js                    Clawd 장면과 그림 칸
hooks/arc.js                      반원 · 퇴근 타이머 · 하늘 · 정각 효과
hooks/poll.js                     요소별 폴링 주기 · 맥 자원 읽기
hooks/config.js                   설정 파일
hooks/fx.js · mascot.js           시작 효과
tests/                            단위 테스트 83개
```

claude plugin validate .
